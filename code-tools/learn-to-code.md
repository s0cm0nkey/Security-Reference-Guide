# Learn to Code

Use this page as the canonical learning index for programming and scripting resources. Bash and PowerShell have their own quick-reference pages, but long-form learning resources should live here to avoid duplicating the same links across the section.

* [Codecademy](https://www.codecademy.com/) - Interactive programming courses.
* [edX](https://www.edx.org/) - Free and paid courses from universities and training providers.
* [Coursera](https://www.coursera.org/) - Online courses, certificates, and degrees.
* [W3Schools](https://www.w3schools.com/) - Introductory web technology tutorials.
* [Codewars](https://www.codewars.com/) - Code challenge platform for practicing problem solving.

* [PowerShell vs Python Reference](https://blog.ironmansoftware.com/powershell-vs-python/) - Practical comparison for automation use cases.
